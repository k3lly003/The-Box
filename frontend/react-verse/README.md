# react-verse

## What it is
React experiments. Right now there's one app: `zustand+ReactQuery/`, a Vite + React + TypeScript app for practicing client state (Zustand) and server state (React Query) with a typed API layer (`src/api/user.ts`).

## Stack
React 19, TypeScript, Vite (SWC), ESLint

## How to run
```bash
cd zustand+ReactQuery
npm install
npm run dev
```
