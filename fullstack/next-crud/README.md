# next-crud

## What it is
A contacts CRUD app built with the Next.js App Router. It has API routes, auth pages, a rich-text editor (Lexical) and MongoDB persistence through Mongoose (`src/model`, `src/utils/database.ts`). The app lives in `nextcrud/`.

## Stack
Next.js 14, React 18, TypeScript/JavaScript, MongoDB + Mongoose, Tailwind CSS, Radix UI, Lexical

## How to run
```bash
cd nextcrud
npm install
# set your MongoDB connection string (see src/utils/database.ts)
npm run dev
```
