# The-Box

My personal learning repo: the projects I've built over the years to level up, grouped by domain. Each project has its own README with notes on how to run it.

## Folder map

```
frontend/      UI work: vanilla JS, React, Next.js, build tooling, static sites
backend/       APIs and services: Django, Spring, Node + Kafka
databases/     Database design and scaling
fullstack/     Apps with both a client and a server/data layer
mobile/        React Native / Expo, Flutter, Android
fundamentals/  DSA and core CS practice
archive/       Superseded versions kept for reference
resources/     Useful links
```
