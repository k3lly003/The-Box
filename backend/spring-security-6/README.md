# spring-security-6

## What it is
A Spring Boot starter project (`com.springvalley.security`) set up for learning Spring Security 6. Right now it has the application entry point and a context test.

## Stack
Java 21, Spring Boot 3.4 (Web), Maven

## How to run
```bash
./mvnw spring-boot:run
# tests
./mvnw test
```
